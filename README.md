# 📋 To-Do List Bot (Telegram, Ruby)

Telegram-бот для збереження списку справ. Кожен користувач має свій окремий список.
Написаний на Ruby з використанням гема [`telegram-bot-ruby`](https://github.com/atipugin/telegram-bot-ruby).

## Технології

| Що | Чим |
|---|---|
| Мова | Ruby 3.x |
| Робота з Telegram API | гем `telegram-bot-ruby` (long polling) |
| Зберігання токена | гем `dotenv` + файл `.env` |
| Зберігання даних | у пам'яті: `Hash` (`chat_id => Array`) |

> Дані зберігаються в оперативній пам'яті, тому після перезапуску бота список очищується (так передбачено завданням).

## Структура проєкту

```
todo_bot/
├── Gemfile        # список гемів
├── Gemfile.lock   # точні версії гемів (створюється bundle install)
├── bot.rb         # код бота
├── .env.example   # шаблон файлу з токеном
├── .env           # твій токен (НЕ комітиться в Git)
├── .gitignore
└── README.md
```

## Встановлення

1. Встанови Ruby (Windows: https://rubyinstaller.org, версія *with Devkit*).
2. Клонуй репозиторій і перейди в папку:
   ```bash
   git clone https://github.com/oleksiikhmelovskyi-akp251k-eng/todo_bot.git
   cd todo_bot
   ```
3. Встанови геми:
   ```bash
   gem install bundler
   bundle install
   ```
4. Отримай токен у [@BotFather](https://t.me/BotFather) (`/newbot`).
5. Скопіюй `.env.example` в `.env` і встав туди токен:
   ```
   TELEGRAM_BOT_TOKEN=123456789:ABC...
   ```

## Запуск

```bash
bundle exec ruby bot.rb
```

У терміналі з'явиться `Бот запущено.` Зупинка — `Ctrl+C`.

## Команди

| Команда | Що робить |
|---|---|
| `/start` | Привітання і довідка |
| `/help` | Список команд |
| `/add [справа]` | Додати справу, напр. `/add Купити молоко` |
| `/list` | Показати всі справи з номерами |
| `/done [номер]` | Видалити одну справу, напр. `/done 2` |
| `/clear` | Очистити весь список |

## Обробка помилок

- `/add` без тексту або з надто довгим текстом (> 200 символів) — бот підказує правильний формат.
- `/done` з не-числом або номером, якого немає, — повідомлення з поясненням.
- Невідома команда — підказка `/help`.
- Звичайний текст без команди — бот пропонує додати його через `/add`.
- Стікер/фото — бот відповідає, що розуміє лише текст.
- Немає токена або він неправильний — зрозуміле повідомлення в терміналі замість падіння.
- Помилка Telegram API при відправці одного повідомлення не зупиняє бота.
